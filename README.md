# 月蝕·狼人殺 主持 App

供一名真人法官在手機、平板或電腦上主持面對面狼人殺。中央顯示主持字幕，法官照念並點選兩側座位，使用「上一步／下一步」控制節奏。

本儲存庫原本只有 `README.md`（內容 `# -`），預設分支為 `main`，沒有舊版程式或美術素材。此初版依「製作狼人殺App」對話重建左右座位、圓形座位號、角色標記及暗黑月蝕色系，不能視為已逐行保留舊版實作。

## 執行方式

安裝 Node.js 22 或以上，下載或複製本儲存庫後，在目錄內執行：

```sh
npm start
```

開啟 `http://localhost:5173`。沒有套件依賴，不需要 `npm install`，不需要後端帳號、資料庫或 API 金鑰。

```sh
npm test
```

測試使用 Node 內建 test runner。也可將 `public/` 放到一般靜態網站服務；ES modules 需要透過 HTTP 開啟，請勿直接雙擊 HTML。

本機伺服器只監聽 `127.0.0.1`，手機需在手機本身開啟已部署的靜態網站；本次提供程式與 PR，未部署正式網站。可用 `PORT` 環境變數更換本機連接埠。

## 目前功能

- 12 人黑狼王／魔術師局：黑狼王 ×1、狼人 ×3、魔術師／女巫／預言家／獵人各 ×1、平民 ×4。
- 左列 1–6、右列 7–12；點座位記錄身分、交換、狼刀、毒殺、查驗、上警、投票結果及死亡技能目標。
- 第一晚依角色睜眼頁認身分，狼人依序點黑狼王再三狼；已標記身分不能重複使用。進入天亮前驗證配置，剩餘四人自動標記平民。後續夜晚沿用身分。
- 主持字幕與法官提示分開；大字幕不顯示真實查驗身分，查驗手勢只放在操作區。
- 必要選擇完成前，下一步鎖定；引擎也拒絕不完整輸入，不會自動代選或跳步。
- 女巫兩瓶藥各一份、同晚互斥；使用時立即更新庫存。兩段字幕每晚都顯示，藥已用完、空刀或當晚使用另一瓶時只鎖操作。
- 上一步以完整狀態快照還原選擇、身分與藥品庫存。公布死亡、確認放逐／技能帶走後建立回退界線，不能用上一步復活已公開死亡者。
- 警長抽籤（1–12＋順／逆時針）、退水、直接指定投票結果、平票 PK。無人上警／全部退水無警長；剩一人直接當選。兩次警長平票流警徽；兩次放逐平票無人出局並進入下一晚。
- 夜間死亡結算、首夜遺言、白天放逐遺言、獵人／黑狼王技能連鎖；被毒不能開槍。死亡先判勝負，最後一神獵人及最後一狼黑狼王不再發動。
- 可關閉的 60 秒發言計時器，時間可調 10–3600 秒，可開始／暫停／重設。關閉視窗可繼續計時，時間到不自動前進。刷新頁面後計時器回到 60 秒。
- 本機瀏覽器自動保存本局、回退快照及紀錄；可重新開局。保存失敗會顯示提示，沒有跨裝置同步。

## 主持流程規格

只有使用者提供的主持句子進入大字幕。沒有定稿台詞的頁面顯示「—」，上方仍有法官操作標題；不要把操作提示當作主持台詞。

| 步驟 | 固定字幕／原句 | 完成條件 |
| --- | --- | --- |
| 開局 | 請確認角色身分 | 下一步 |
| 夜晚 | 天黑請閉眼 | 下一步 |
| 魔術師 | 魔術師請睜眼 | 首夜點本人；後續不再認角色 |
| 交換 | 選擇你今晚要交換的對象 | 兩名不同存活玩家，或「不交換」 |
| 閉眼 | 魔術師請閉眼 | 下一步 |
| 狼人 | 狼人請睜眼 確人彼此角色身分 | 首夜先黑狼王、再三狼；「確人」保留原稿，未擅自改字 |
| 襲擊 | 選擇你們今晚要襲擊的對象 | 一名存活玩家，或「空刀」；可自刀 |
| 女巫 | 女巫請睜眼 | 首夜點本人 |
| 解藥 | **今晚他死了，你要使用解藥嗎？** | 「使用解藥／不使用解藥」；不可用時直接下一步 |
| 毒藥 | **你要使用毒藥嗎？你要毒誰呢？** | 「不用毒藥」或「使用毒藥」＋一名目標；不可用時直接下一步 |
| 閉眼 | 女巫請閉眼 | 下一步 |
| 預言家 | 預言家請睜眼 | 首夜點本人 |
| 查驗 | 選擇你今晚要查驗的對象 | 一名存活玩家 |
| 結果 | 預言家請閉眼 | 法官操作區顯示 👍／🐺；下一步 |
| 獵人 | 獵人請睜眼 | 首夜點本人 |
| 手勢 | 今晚的開槍手勢 | 法官查看操作提示，下一步 |
| 閉眼 | 獵人請閉眼 | 下一步 |
| 天亮 | 天亮請睜眼 | 首夜先競選；次夜起進死亡公布 |
| 競選 | 現在開始競選警長，候選人請起立 | 點上警名單，或「無人上警」 |
| 抽籤 | 抽發言順序 | 按抽籤 |
| 政見 | X號Y時針發表政見 | 代入抽籤號碼／順逆時針；可計時、點候選人退水 |
| 退水 | 要退水的玩家請坐下 | 確認剩餘名單 |
| 警長投票 | 現在進行投票 3 2 1請投票 | 點當選者，或「平票」＋至少兩名平手者 |
| 警長 PK | 請平手玩家依序再次發表政見 | 發言完下一步 |
| 再投票 | 再次準備投票 | 點 PK 當選者，或再次平票 |
| 結果 | X號當選警長 | 下一步；無警長分支無新增台詞 |
| 夜間公布 | 昨晚是平安夜／昨晚X號和Z號被殺死 | 按下一步確認死亡成立，鎖定回退界線 |
| 遺言 | X號玩家出局，請發表遺言 | 首夜夜間死者或白天放逐者；下一步 |
| 技能 | X號玩家，啟動角色技能 | 一名存活目標，或「不發動技能」 |
| 方向 | 警長決定警左警右 | 必須選警左／警右；無警長時由法官選 |
| 白天發言 | 尚無定稿字幕 | 使用計時器；發言完下一步 |
| 投票準備 | 現在進行投票 | 下一步 |
| 放逐 | 3 2 1請投票 | 点淘汰者，或平票＋至少兩名平手者 |
| 放逐 PK／再次投票 | 尚無定稿字幕 | 計時，之後僅可點 PK 玩家或再次平票 |
| 下一晚／勝負 | 尚無定稿字幕 | 操作標題提示結果；下一晚回到天黑流程 |

已出局角色不再接受夜間目標操作，但字幕頁仍由法官控制前進。女巫的固定兩段字幕不會因此刪除。投票僅記錄法官判定的結果，不計算每名玩家票型。

### 結算與回退

魔術師記錄的是本晚目標映射，不更改座位真實身分：交換 A／B 後，狼刀、毒殺、查驗目標 A 對應 B，B 對應 A。女巫操作區顯示原始狼刀；解藥取消原始狼刀效果後再映射。毒殺和狼刀落在同一最終玩家時以毒死記錄，因此不能開槍。

夜間死亡先暫存，首夜警長竞選结束後才公布。死亡公布頁按下一步時同批死亡成立，先判定勝負（全狼死亡好人勝；神職或平民全部死亡狼人勝），再處理遺言與技能。首夜夜間死亡有遺言、之後夜間無遺言；技能帶走無遺言但可繼續合法技能連鎖。

尚未公布的夜晚操作可回退修正；跨過公布界線後沒有自動更正／復活功能。發現公開結果有誤時需停止並由真人法官處理，目前不能透過 App 修改公開死亡。

## 專案結構與 Codex 接管

```text
public/index.html       畫面結構與對話框
public/style.css        暗黑月蝕風格及手機排版
public/app.js           座位與按鈕、保存、計時器
public/engine.js        字幕、狀態機、驗證、回退、結算
test/engine.test.js     12 組核心規則回歸測試
server.mjs              零依賴本機靜態伺服器
AGENTS.md               後續 Codex 不可違反的約束
.github/workflows/      Push／PR 自動執行測試
```

接手時先讀 `AGENTS.md` 與此 README，確認最新分支及使用者的新決定。先改純引擎再接 UI；所有主持台詞集中於 `SCRIPT`／`subtitle`，操作提示位於 `app.js`，不要混用。修改必要選擇、回退、藥品及死亡時，新增針對行為的測試後執行 `npm test`。修改畫面須人工查看桌面與手機；既有核心測試不代表畫面驗證。

### 待使用者定稿／後續項目

- 無警長、白天發言、放逐 PK／再投票、勝負等分支的正式主持台詞。
- 魔術師跨晚是否禁止重複交换、女巫自救限制、預言家是否可驗自己等特殊細節；初版只有存活與選擇數量限制，不自行加限制。
- 警徽移交／撕毀、警長死亡後的發言順序細節；初版死亡清除警徽，方向由法官選擇，沒有自動發言輪轉。
- 已公開結果更正、紀錄匯出、暱稱／頭像／筆記、10 人局、PWA／正式部署。
- 若提供舊版程式與美術，可再對照還原原始素材及更細的座位操作。

此版不包含多人連線、玩家帳號、聊天室、自動語音或雲端資料庫。字幕補充必須先有使用者定稿。
