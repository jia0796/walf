## 主持與結算原則

1. 字幕逐字沿用定稿，法官提示與字幕分開。
2. 女巫固定「**今晚他死了，你要使用解藥嗎？**」，不補號碼；藥已用完或同晚已用藥，兩段字幕仍照走，只限制操作。
3. 必要選擇未完成不能前進；合法的空刀、不交換、不使用／不發動技能依各板規格提供。
4. 當晚開始時存活者仍可完成當晚合法行動；傷害先判勝負，座位死亡到公告才更新。真正終局立即停止後續階段。
5. 狼刀確認保護與可能解藥後優先結算；同一不可拆分批次雙陣營同時達標，依全域規則判狼人勝。
6. 死亡、恐懼或無法操作不任意刪除字幕；不把特殊情境口頭說明加成固定流程。
7. 主持座位不放人物插圖；人物只用圖鑑、終局回顧及復盤。
8. 上一步完整恢復選擇、消耗、死亡、標記及復盤資料。

以上是導讀；邊界條件依完整規格第 7～9、16、16.1、32、33 章及各板最新章節。

## 執行方式

需要 Node.js 22 以上。程式沒有額外執行依賴，使用 App 分支：

```sh
git clone --branch feat/eclipse-host-app https://github.com/jia0796/walf.git
cd walf
npm start
```

開啟 `http://localhost:5173`，可用環境變數 `PORT` 更改埠號。

```sh
npm test
```

原生 JavaScript 靜態 PWA，沒有獨立 build 或 TypeScript 檢查；發布目錄是 `public/`。額外黑箱測試 `scripts/ui-regression.mjs` 需要可用的 Playwright／瀏覽器環境；壓力與 UI 參數見報告。
