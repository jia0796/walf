# 月蝕・狼人殺主持 App

本專案方向為「狼人殺真人法官主持 App」。

App 不取代真人法官發言，而是提供：
- 主持字幕
- 上一步／下一步流程
- 角色與座位標記
- 夜間操作紀錄
- 警長流程
- 發言計時器
- 死亡、角色技能與勝負流程輔助

目前優先完成 12 人局主持流程。

---

## 主持流程核心原則

1. 法官台詞以既有定稿內容為準，不自行改寫或補字。
2. 需要法官完成操作的頁面，在必要條件尚未完成時，按「下一步」不得前進。
3. 固定提供「上一步」以修正尚可回復的誤操作。
4. 第一晚認角色只做一次；第二晚起 App 已記錄角色。
5. 魔術師必須選滿兩名對象，或選擇「不交換」。
6. 狼人必須選擇狼刀目標，或選擇「空刀」。
7. 獵人／黑狼王符合資格時，可點選一名存活玩家，或選擇「不發動技能」。
8. 女巫同一晚不可同時使用解藥與毒藥，但固定主持台詞仍須完整走完。
9. 女巫解藥台詞固定為：**「今晚他死了，你要使用解藥嗎？」**，不可自行補報座位號碼。

## 警長死亡後的警徽落處

主持字幕簡化為：

> **請警長移交警徽**

不需要報警長座位號碼。

警長死亡後若同時存在角色技能／死亡連鎖，採用 **B 流程**：

1. 先處理該次死亡應有的遺言。
2. 處理死亡玩家自己的角色技能。
3. 若技能造成新的死亡，繼續把**整條死亡／角色技能連鎖全部處理完成**。
4. 每次新死亡仍依遊戲規則檢查是否已達勝負條件。
5. 整條技能連鎖處理完成、且遊戲尚未結束後，才回頭處理原警長的警徽落處。
6. 顯示：**「請警長移交警徽」**。
7. 警徽移交目標必須是當下仍存活的合法玩家；另提供撕警徽／不移交的對應操作（具體按鍵文字後續再定稿）。

## 待檢查 Bug：第二天夜晚技能帶走玩家後缺少出局字幕

### 實際操作情境

第二天夜晚，獵人發動角色技能並帶走一名平民。

### 目前錯誤

技能目標死亡後，流程**沒有跳出**：

> **X號玩家出局，沒有遺言。**

而直接略過了被帶走玩家的出局提示。

### 預期行為

第二天夜晚起，因角色技能造成的死亡若沒有遺言資格，仍然必須顯示：

> **X號玩家出局，沒有遺言。**

之後才繼續：
- 檢查該死亡玩家是否還有合法角色技能可發動。
- 檢查是否形成新的死亡連鎖。
- 檢查勝負。
- 若流程全部處理完，再前往後續階段。

### 待程式檢查方向

請檢查死亡處理流程是否只對「有遺言」的死亡建立字幕頁，導致「無遺言」分支直接被略過。

特別檢查：
- 第二夜及之後的夜間死亡。
- 獵人／黑狼王技能造成的死亡。
- 被技能帶走的是普通平民時。
- death queue / death resolution 是否在 `hasLastWords === false` 時直接 advance，而沒有建立「X號玩家出局，沒有遺言。」步驟。

## Codex 接管注意事項

Codex 修改程式時：

1. 先以本 README 的「修改紀錄／待修正」作為目前最新規格。
2. 不自行更改法官主持台詞。
3. UI 提示文字與法官字幕要分開處理，不能把開發註解／規則提示加入主持字幕。
4. 任何必要選擇都需支援取消／更正，並確認「上一步」能恢復合理狀態。
5. 修改死亡流程時，優先確保每一個死亡事件都會被處理一次，不能因「沒有遺言」而完全沒有出局提示。
