## 主持與結算原則

1. 字幕逐字沿用定稿，法官提示與字幕分開。
2. 女巫固定「**今晚他死了，你要使用解藥嗎？**」，不補號碼；藥已用完或同晚已用藥，兩段字幕仍照走，只限制操作。

6. 死亡、恐懼或無法操作不任意刪除字幕；不把特殊情境口頭說明加成固定流程。
7. 主持座位不放人物插圖；人物只用圖鑑、終局回顧及復盤。
8. 上一步完整恢復選擇、消耗、死亡、標記及復盤資料。

### 48.2 身分、隊友與帶刀資格

- **隱狼**是真狼人陣營，但**不認識其他狼、其他狼也不認識隱狼**；從不跟狼隊睜眼、討論、刀人、接刀或自爆。狼隊可以正常選隱狼作普通襲擊目標，依同板防護結算。預言家查驗隱狼回傳**好人 👍**，但其真實陣營、最終勝負仍是狼人。
- **感染成功者**在該晚防護正式結算時立刻成為**狼人陣營的普通帶刀狼**，即刻永久失去原身分技能，原始角色仍保留作紀錄；**不等待夜末輕觸肩膀才改陣營**。**下一夜起**才和狼隊共同睜眼、自然認識原狼隊並加入共享狼刀，不新增任何額外攻擊，不獲得種狼感染技能。
- **感染當晚不通知原狼隊成功／失敗**，不讓新感染者當夜追加刀。新感染者成功後就算**帶刀狼**供勝負判斷：原始狼全滅但新感染者還存活，不可判好人勝；他下夜可自行刀人。即使還未到下一夜，新感染者**隔天已可自爆**。
- 感染成功者若是現任**警長／警徽持有人，仍保留警徽及原有警長權限**，之後出局才按現有警徽移交或撕毀規則處理。感染者（含後來已死亡者）最後跟**狼人陣營一起勝負**；感染失敗者保持原職、原陣營及對應勝負歸屬。

### 48.3 感染發動、合法目標與二次確認

> **現況／下一版區分：** 下列「襲擊／感染模式切換＋確認視窗」為上一版操作。本輪已改為「一般狼刀選目標 → 下一步 → 是否發動感染？」單一詢問視窗，取消模式切換；新操作細節以下方本輪章節為準。消耗、防護、勝負等遊戲規則照本章不變。

1. **第一夜不可感染**。**第二夜起**，若種狼仍存活且尚未用技能，可選擇那一晚或任一往後夜晚**發動一次**，不強制第二夜使用；種狼提早出局且從未發動則技能失效。
2. 感染不是另一次刀，必須使用狼隊**當晚共同選中的同一目標**，在「襲擊／感染」間擇一。感染是**取代本晚基本狼刀**；不另選第二人，也不能同晚再補基本刀。
3. 狼隊選目標、切換「感染」都**不扣技能**。法官按「下一步」後開**與現有 App 一致的深紫液態玻璃確認視窗**：「**確認發動感染？**」「**本局僅能使用一次感染技能，正式發動後無論成功或失敗，都會消耗次數。**」，提供「取消」與「確認感染」。取消返回編輯且不扣次數，按下**確認感染**才正式扣掉唯一一次。已用技能／種狼死後，往後夜晚感染操作不可選，但主持字幕保留。
4. **正式發動即消耗一次**，成功或失敗均不退回；**失敗不恢復普通狼刀，也沒有感染附加刀殺**，但獨立毒藥或同守同救等合法死因仍可能致死。若發動後種狼自己在**同一夜**死亡，已正式發動的感染仍有效，不因施法者死亡撤銷。
5. 感染選目標可選**任一存活座位**，包括**種狼自己、普通狼人、隱狼、先前已成功感染的新狼人**，**不可在 UI 禁選狼人目標而暴露陣營**。感染任何**已是狼人陣營**的人必定失敗，仍扣次數、仍取代普通刀；該目標保有原職、真陣營和技能。失敗結果只供法官內部結算與終局復盤，不從公開字幕洩漏。

### 48.4 守衛／解藥／同守同救／毒藥

- **守衛單守**感染目標：阻止感染，若無其他獨立死因則目標存活；**女巫單獨以合法解藥救**感染目標：阻止感染，若無其他獨立死因則存活。守衛此前同夜已合法發動在其他座位的守護**不因他稍後被感染而追溯取消**；感染後不可再守。
- **同守同救必死**：若守衛有效守護、女巫有效使用解藥在當晚**同一感染目標**，目標**不感染、仍以原職業／原陣營死亡**。**即使目標本來就是狼人、種狼感染自己或原本注定感染失敗，也照樣因同守同救死亡**；不可因感染失敗就略掉死亡。
- 女巫在夜間仍只看**狼隊選的目標座位**，**不知道是襲擊還是感染**，亦不知道是否成功；沿用固定字幕「**今晚他死了，你要使用解藥嗎？**」等，不加結果提示。女巫**正式合法使用解藥就消耗**，就算目標原本是狼人、感染注定失敗也**不退藥**。女巫自救開關／同晚只能用一瓶藥照舊。
- **感染女巫本人**時，仍先依本板現有房規給其**合法解藥／自救決策機會**；若有效解藥阻止感染，女巫維持原身分及技能；若感染在防護結算後成功，女巫當晚**立即失去剩餘用藥能力，不能再毒**。同理預言家被感染不能查、獵人被感染不能槍。
- 感染成功之後，若感染者同夜被女巫合法毒殺，他**先變狼人，後以狼人真陣營死亡**。只要尚未正式終局，依 48.6 節**仍須夜末輕觸肩膀通知**；不能以內部死亡標記略過。毒藥、防護、感染均不得在其合法結算時點前提前套用勝負。
- **12 人獵人特例**：感染**失敗**時若同守同救殺死原獵人，該玩家仍是獵人；符合既有狼刀相關死亡槍條件、且**尚未正式終局**時可以在既有白天流程開槍。屠邊最後一神因此出局若已狼勝，就**不可補槍**。獵人**感染成功**後永久無槍，後來同晚毒死亦不例外。

### 48.5 勝負判定與狼刀在先

- **屠邊**：最後一位真好人神職或最後一位真好人平民即使**不是死亡而是成功感染**，也已退出原好人職別，狼隊在**感染完成結算當刻獲勝**；同守同救讓最後一神／民以原職死亡，亦可直接狼勝。
- **屠城**：所有好人均死亡或成功改狼人陣營時才狼勝，不能把屠邊條件誤用在屠城。
- **好人勝**：所有真正**帶刀狼**（種狼、普通狼人、成功感染的活狼）正式全數出局，且此前狼人未先獲勝。**當場只剩隱狼，立即好人勝**；隱狼不能接刀。已感染但還未到下一晚參與刀的新狼人，仍屬當前帶刀狼。
- **第 16／16.1 節狼刀在先**：狼人選擇目標不代表正式死亡或感染；**需先等守衛、女巫解藥及同守同救判定完成**，正式一次結算狼刀／感染與相連死亡、立即檢查勝負；若已達任何一方終局，跳「**天亮請睜眼**」→「**遊戲結束**」，不補尚未執行的毒、查驗、獵人、感染者確認等流程。沒終局才處理女巫毒藥等後續獨立階段，彼此已完成的合法傷害不因後續事件被回溯。
- 同一**不可拆分的死亡批次**兩陣營同時達勝利條件，沿用**狼人勝、沒有平局**；不因本板感染取代普通狼刀而更改全域優先序。白天自爆／槍等每次正式結算後也立即查勝負。

- **第一晚「隱狼請睜眼」顯示時，法官才在該頁直接點選隱狼玩家的座位，正式登記其角色身分**；不只是對開局已指定的隱狼按「確認身分」。必須選擇**恰好一個合法座位**後才可按「下一步」，接著顯示「**隱狼請閉眼**」。此操作是**身分登記，不是技能目標**，不新增選人技能或第二次登記。

5. 基本橫向**雙人物技能卡**固定從左至右：**施技者的核准職業原畫 → 施技者「職業名稱（上）／座位號碼（下）」→ 正式技能 SVG（中央）→ 受技者「職業名稱（上）／座位號碼（下）」→ 受技者核准職業原畫**。職業名與號碼是同一垂直區塊，不可水平拆開。兩側個別依**該事件時點的真實陣營／職別**上色：狼人紅、好人神職金、平民綠，沿用 App 已核准的正式色碼；座位號同色。SVG 保留正式原配色，不隨角色改色。隱狼、機械狼及其他真實狼陣營者不因查驗偽裝改用好人色；特殊身分變化見第 4 小節。
6. 中央技能 SVG **上方**有需要時顯示具體標記，例如**成功、失敗、免疫、守護抵擋、解藥救回、連帶、連攝、毒藥觸發、查驗觸發**。具體用語與原因來自已保存的真實結算；若本技能有更精確的下列專屬標記，以專屬規則優先。正常成功而無需區分結果時只顯示 SVG。不因結果額外製造重複卡，亦不得把「施放成功」混同「目標死亡」。
7. 人物只使用已核准的原始角色插畫，正式技能只使用核准 SVG；圖片等比例、不拉伸。已定的職業簡稱（如 **`機械狼(通)`**）優先，沒有必要為假想極長職業名縮成難讀小字。手機雙指縮放、字級、安全區、無橫向溢出與長局捲動要驗收。

### 2. 白天事件與投票卡（最新五區塊版型）

**警長競選**固定五區塊（左至右）：

> **警徽插畫 PNG →「警長競選」→ `icon-sheriff-badge.svg` → 當選者「職業（上）／X號（下）」→ 當選者核准職業插畫**

- 只記錄**最終警長競選結果**：當選者或「平票／無警長」等真實結果。**不記錄／顯示個別票型、上警及退水玩家**；第一次平票但後續已選出警長，顯示最終當選者，不虛構逐輪明細。
- 平票／無警長時左邊警徽插畫與中央警徽 SVG 保留，右側只顯示結果，**不顯示職業插畫或不存在的當選者**。

**放逐投票**採取與警長競選一致的**最新五區塊版型**（取代以前「職業／號碼 → 放逐出局」單人物卡）：

> **投票插畫 PNG →「放逐投票」→ `icon-vote.svg` → 被正式放逐者「職業（上）／X號（下）」→ 被放逐者核准職業插畫**

- 正常有效放逐**只建立上述一張放逐結果卡**，**不再另建「放逐出局」單人物卡**；死亡及連鎖技能依真實結算資料運作，避免同一放逐重複紀錄。
- **保留 PK 過程但不記逐票票型**：首次放逐平票，另有「放逐平票：X號、Y號（或實際多人）進入 PK」事件；之後再依真實流程顯示 PK 的最終放逐結果，或「平票／無人出局」。**不能把 PK 尚未決出時寫成已出局**。
- **最終平票／無人出局**保留投票事件名稱與投票 SVG，但**不擺不存在的出局角色插畫**。沒有發生的 PK／額外投票不得補錄。
- **白痴遭有效放逐而觸發翻牌**：改以獨立「白痴翻牌」卡呈現，**不當成放逐死亡、不得同時製造「放逐出局」卡**；白痴既有翻牌後權限／規則照舊。

**其他白天單人物事件卡**統一：

> **角色核准插畫（最左）→「職業名稱（上）／X號（下）」→ 箭頭 → 事件名稱**

- **狼人自爆**：事件名稱「自爆出局」；照自爆種類、時機與既有禁止開槍等房規執行。
- **白痴翻牌**：事件名稱「白痴翻牌」，**翻牌≠死亡**；不得變成一般出局狀態。
- 其他同性質的單人物白天結果事件才沿用此排版；**不覆蓋警長競選／放逐投票的最新五區塊專用版型**。
- **白天實際開槍**（獵人、黑狼王、幸運兒額外獵槍及其他合法槍擊）採一般**雙人物＋正式槍 SVG**。未開槍無卡；合法發動各筆獨立。夜間死亡而白天才合法開槍者放在當日白天，不倒回夜間。白天任何技能、警徽、放逐及連鎖事件依真實發生順序穿插，不強制排到日末。

**警徽異動**：
- **移交警徽**：一般雙人物卡；左為原警長原畫及職業／號碼，中間 **`icon-sheriff-badge.svg`**，右為接任者職業／號碼及原畫。
- **撕毀警徽**：沿用移交警徽卡樣式，保留左側原持有人，中央警徽 SVG，**右側改為醒目 X（無接任者）**，不要虛構右側人物。
- **吞警徽**（狼人雙爆情境）**不建立獨立復盤卡**；如已合法發生自爆則照常留下自爆事件；內部仍須保存警徽消失及雙爆等真實狀態，讓主持／勝負／回退不受影響。

### 4. 特殊身分與終局順序

1. **感染／轉化事件當晚**右側目標顯示**該事件時點的原職業、原配色及原畫**；身分變化後**下一晚起**，往後技能事件中名稱分別顯示「**感染者**」與「**轉化者(原職簡稱)**」，使用原職業插畫，狼人陣營紅。**這是復盤顯示切換時機**；實質真陣營轉換、技能封鎖與狼刀資格仍按既有引擎的即時／次夜規則，不得延後實質結算。
2. 機械狼學習後使用「機械狼(簡稱)」；例 `機械狼(通)`。隱狼真實陣營為狼人，查驗偽裝不改復盤配色。幸運兒用原職插畫及「幸運兒」卡面名稱。混血兒按**真實陣營**分組，不因跟隨狼隊的**個人勝負**自行移入狼隊。
3. **遊戲結束結算卡放在完整復盤最上方，採精簡版**：只顯示**「勝利陣營＋勝利原因」**；不顯示結束於第幾天／夜、日期或玩家個人勝負。由既有正式勝負結果自動生成。
4. **最終身分回顧**直接接在同一復盤視窗**最下方**，不需要另外點擊、不使用收合。**狼人陣營區在上，好人陣營區在下**；狼人區按座位號碼由小到大；好人區**神職在前、平民在後**，兩類各自按號碼由小到大，**每排固定兩張角色卡**。
5. 每張最終身分卡：**左側核准原職業插畫 → 右側職業名稱（上）／座位號碼（下）／「存活」或「出局」**；職業／號碼沿用職別陣營配色。感染者／轉化者額外顯示**「原職：XXX」**，插畫仍保留**原職業圖**。**不顯示個人「勝利／失敗」**（即使引擎本身仍保留個人勝負）。較複雜角色可保留已定必要身分標示，但不藉此恢復被取消的個人勝負欄位。
6. 長局一律**整個復盤面板垂直捲動**（頁背景仍固定）、雙欄不改成單欄，職業與號碼不拆散、圖片不變形，不能橫向溢出或遮擋返回／關閉操作；安全區與 iPhone Safari／安裝 PWA／Android 真機另驗收。

### 1. 畫面結構（同一計時器視窗、兩種模式）

| **設定模式** | 可滑動的「分鐘／秒數時間滾輪」，**左側 −10 秒**、**右側 +10 秒** | **開始**、**重置** | **重設** |
| **倒數模式** | **單純大型 MM:SS 數字**，不顯示滾輪或滾輪外框 | **暫停／繼續**、**重置** | **重設** |

- **設定模式排列**：`−10秒　［分鐘／秒數滾輪］　+10秒`，下方兩個主按鈕「開始」「重置」，以及尺寸明顯較小的「重設」。沿用 App 正式配色與易點按的觸控範圍；不能因為視覺較小就小到難以操作。
- **倒數模式排列**：畫面中間突出大型倒數數字 `01:30`；滾輪／±10秒隱藏。下方「暫停」（暫停後文字換「繼續」）、「重置」為主要按鈕；「重設」維持較小。不要在倒數中仍保留可見的滾輪背景、遮罩或假滾輪。
- 手機直式、橫式、平板、字級與雙指放大時，不得橫向溢出或擋住按鈕；計時器仍是主持流程中的同一個彈窗，不修改遊戲本身。

### 2. 開始／暫停／繼續與動畫

1. 法官先用滾輪或兩側 **−10秒／+10秒** 設定時長；例如 **01:30**。調整須正確跨分鐘計算，例如 `01:55 +10秒 = 02:05`；不允許負數，設定範圍沿用現行計時器合法上下限。
2. 按 **「開始」**：保存當次**原設定時長**作為「重置」目標值；播放約 **0.25～0.35 秒**的平順淡入淡出／輕微縮放動畫，**由時間滾輪切換為純大型數字**，並開始正常倒數。動畫不能使時間重複扣除、跳秒或延遲計時邏輯。
3. 在倒數模式按 **「暫停」**：保留剩餘時間、停止倒數、主按鈕改顯示**「繼續」**，**畫面維持純數字**；按「繼續」從該剩餘時間繼續，不重新開始，也不恢復滾輪。
4. 倒數到 **00:00** 後仍可按「重置」或「重設」，不用重新輸入分鐘／秒數。

### 3. 重置 vs 重設（兩個模式都提供）

- **重置（主按鈕）**：**保留法官最後設定且已用於開始倒數的原始時長**，例如設定 `01:30`，倒數剩 `00:43` 時按重置 → **停止計時，恢復 `01:30`，並以返回動畫切回可操作的「時間滾輪設定模式」**。即使倒數結束也同樣適用。設定模式中按重置，回到最近一次開始所記住的設定時長；若本次尚未開始，則維持本次已設定時長，不無故改回 01:00。
- **重設（小按鈕）**：**放棄目前設定與剩餘時間**，一律回到預設 **`01:00`**；停止倒數，**同樣播放返回動畫並回到有滾輪的設定模式**，滾輪數值顯示 01:00。設定模式中按重設則直接更新滾輪至 01:00；不必播放已在相同模式的切換動畫。
- **返回動畫**：從倒數模式按重置或重設時，大型數字淡出／微縮，**分鐘／秒數滾輪與兩側 ±10 秒淡入**；約 0.25～0.35 秒。**再次按開始**仍會重新播放設定→倒數動畫。不可切到只有數字卻沒有滾輪可編輯的「假設定模式」。
- 更新計時器畫面與狀態時要處理動畫中連續點按、暫停後重置、00:00 後重置、反覆開關彈窗等情況，避免多重計時執行或殘留舊模式。尊重作業系統的減少動態效果偏好。

### 49.4 狼美人：魅惑、殉情與限制

1. 狼美人與普通狼人**共同睜眼、共同參與唯一基本狼刀**；**不能自刀、不能自爆**。普通狼既有合法狼刀／自爆規則不藉本板變更。
2. 狼美人每晚可選**一名其他存活玩家**魅惑，也可選擇**空魅惑**；不可選自己或已出局者。**普通狼人隊友也可魅惑**，狼刀目標亦可同晚成為魅惑目標。
3. **不能連續兩晚魅惑同一玩家**；中間有一晚空魅惑，就可在下次合法魅惑時重新選擇該玩家。魅惑**不跨夜累積**，每晚以當晚正式選擇為準，空魅惑不沿用前一晚目標。
4. 狼美人經合法**白天放逐**、**獵人開槍**出局時，若當晚有有效魅惑，觸發當前對象**殉情出局**；因女巫毒藥出局是否觸發，依下節房規。**騎士決鬥狼美人出局時一律不觸發殉情**，任何房規也不能改寫此例外。
5. 被魅惑玩家因其他合法死因**已正式出局**，不再重複死亡、不新增第二個殉情死亡或虛構的殉情事件／公告；當晚實際施放過的魅惑事件仍照實保留。
6. **殉情者沒有遺言；殉情出局的獵人不能開槍。**若獵人同夜既遭狼刀又因狼美人死亡而符合殉情禁槍條件，實際出局**只記一次**，仍**禁止開槍**；不加特殊禁槍復盤卡或顯示標籤。不可追溯取消獵人**已於合法較早階段實際開出**的槍。僅被狼刀殺死、未真正觸發殉情的獵人，仍依原有槍枝規則。
7. 若未來其他板子同時包含守衛，既有守護不抵擋已觸發的殉情；**本章兩板並無守衛**，不擅自新增其夜間階段。

### 49.6 騎士：白天一次決鬥

1. 騎士是**好人陣營神職**。僅**存活且尚未使用技能**時，可在**正常白天、正式放逐投票開始之前**，藉主持控制區**獨立「騎士決鬥」入口**發動一次；**不可於警長競選或 PK 中發動**，不綁定、不新增、不更動座位卡的「目前發言」標記或發言順序。
2. 選一名**其他存活玩家**為目標；**二次確認**前允許取消、返回、改選，且不消耗技能。正式確認當下公開**騎士本人的身分**、消耗一次技能、按目標**真實陣營**立即結算死亡及勝負；公開牌面僅顯示決鬥結果，**不揭露目標具體職業**。
3. 若目標是任何狼人（含狼美人），**決鬥成功，目標出局**；該玩家**沒有遺言**，若是狼美人則**不觸發殉情**。若未達終局，跳過本日正式放逐投票，必要警徽處置完成後**直接進下一夜**；不得捏造未發生的投票事件。
4. 若目標是好人，**決鬥失敗，騎士自己出局**；騎士**沒有遺言**，目標存活。若未達終局，處理必要警徽後，**回到原本白天主持流程**，仍可正式放逐投票，不變動發言標記／進度。
5. 正式確認後呈現**獨立決鬥結果頁**，成功字幕逐字為「**決鬥成功，X號出局，沒有遺言**」；失敗逐字為「**決鬥失敗，騎士出局，沒有遺言**」。須按**「下一步」**才進行畫面導航；**結算只執行一次（確認當下），下一步不可重算或重複記卡**。
6. 決鬥出局者如持有警徽，**未正式終局**時沿用原有**移交／撕毀**處理（不能交給已出局者）；已正式終局則不補警徽或其他尚未執行的流程。騎士能力與警徽、死亡、復盤均須完整回退／恢復。

### 49.7 正式傷害批次、勝負優先與公開主持公告

- **全域結算沿用第 16／16.1 節**：狼刀在合法防護確認後**先正式結算並立即檢查勝負**；若此時遊戲已正式終局，跳過尚未執行的女巫毒藥、查驗、獵人等階段，不為了補技能產生假事件。若未終局才繼續依夜間順序處理後續合法傷害。
- 同一合法狼美人死亡所觸發的**殉情與該次死亡為同一正式死亡／勝負結算批次**；不能在殉情計算完成前先宣告好人勝。若同一不可分割批次中同時滿足兩邊勝利，依現有優先規則**狼人勝**；不設平局。**同批殉情**與**前一階段已完成的狼刀批次**不得錯誤合併。
- **夜間**狼美人遭女巫毒殺並觸發殉情，天亮仍只按原有主持格式**統一公告所有正式死亡座位號**，每人一次；**不公開死因、殉情機制或職業**，不新增獨立夜間殉情公告頁。
