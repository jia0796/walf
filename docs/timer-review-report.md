# 計時器與復盤 UI 修正報告

依據：main@3956df4 README 計時器定稿；使用者提供「優化界面討論復盤」預覽中的恐懼提示、結算置頂、好人排序与人物融合要求。以 feat/eclipse-host-app 現有程式修改，發布待本次提交後核對。

## 修正與完成

1. 首夜預言家已登記但其他角色未全辨識時，rolesConfirmed=false 擋住恐懼提示，查驗結果頁因此誤顯「預言家已出局」。移除該顯示門檻；合法辨識仍須完成，恐懼照常封鎖查驗，毒殺待正式公告才更新座位。沒有修改傷害／勝負引擎。
2. 遊戲結束的精簡陣營／原因欄移到完整復盤最上方；之後仍按日夜事件順序，最終身分在底部。
3. 狼區升序；好人區先神職、再平民，每類升序，固定雙欄。真實陣營與混血兒民位不變。
4. 人物從核准原圖沿既有 recapCrop／artSize 做 SVG viewBox 裁切，左右遮罩融合進玻璃背景；基本狼刀按實際圖片角色取裁切參數。混血兒依原 JPEG 實測1089×1445新增顯示裁切範圍，避開牌框／名稱牌。原始圖檔不改。示例附件未傳入，無法逐像素比對，採沿用原有融合方向的實作。
5. 計時器保留原滾輪，新增獨立 deadline 控制：設定模式有±10秒與開始／重置，較小重設；倒數模式只有大型MM:SS與暫停／繼續、重置及重設。
6. 重置保留最後已開始的時長，尚未開始則保留目前設定；重設清記憶並回60秒。暫停不回滾輪；到0仍可重置。300ms淡出／縮放與淡入，動畫不影響時間，減少動態時不播放；連按撤銷旧動畫／影像，始終唯一 interval。
7. 快取 council-v13-4；主持存檔／歷史不被計時器改寫。時間刷新後沿用既有重開預設，不新增計時器持久化。
