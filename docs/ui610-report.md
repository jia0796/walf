## 待真機驗收及限制

1. iPhone Safari 的地址列伸縮、Home Indicator／Dynamic Island、雙指縮放、三層捲動手勢及背景恢復。
2. iOS 安裝版 PWA、Android、低階裝置效能；桌面 Edge 模擬與合成 PointerEvent 不等於這些裝置通過。
3. 320px、橫向或放大字級時，中央字幕會更頻繁換行。依最新要求，直式把六排座位縮小容入；最終85／15版面下，320×568座位約58.77px、375×667約71.08px、390×844及430×932為80px；844×390橫向約36.64px，職業最小約7px，辨識度及小按鈕點擊舒適度需真機確認。15%操作區不會同時顯示所有工具／技能／流程按鈕，需內部滑動；這是最新配置的呈現結果。
4. 新背景原檔約 2.11MB，未壓縮或重製核准圖；弱網首次讀取及低階裝置 blur 效能仍需實測。
5. 離線首次安裝需先完成線上受控載入；本輪沒有擴充預快取範圍。

