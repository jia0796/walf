## 本輪額外發現與處理

1. **可視高度被最小高度蓋過**：縮小 viewport 20px 時，原 min-height:100vh 仍強制 main 按原高度布局。實測可見主容器 568px 而指定可視高度 548px；修正後 main 為 548px，320×568 下底部按鈕完整位於安全區以上。這是模擬中已定位的 CSS 問題，不宣稱已證明所有實際 iPhone 的唯一根因。
2. **混血兒三行被長名稱樣式覆蓋**：既有 long-name 選擇器優先造成角色字體過大，平板首行超出卡頂；修正選擇器與三行高度，小尺寸技能標記側置，警徽與文字邊界均通過。
3. **回退感染確認**：正式感染後回到相同選座，保存的確認狀態可直接重執行感染，使新介面不能改不感染。回退清除確認旗標但保留目標；下一步重新詢問，不重扣、不造幽靈事件。
4. 測試另修正新增閉眼／結果頁的步數假設、存檔 v13，以及非同步快取等待過早完成。後者曾使測試在下載未完成時切離線，屬測試等待問題；改為等待實際 Cache API 結果後，43 素材全部通過。

## 實測

- **442 項 Node 測試，0 失敗、0 跳過**。包含新增逐板閉眼、首夜隱狼、單次感染詢問、回退重詢、機械第二／三／四夜、混血兒結果、文案及快取故障測試。
- **三組壓力**：offset 0 每配置 18 局、offset 500／5000 各每配置 54 局，共 **2,646 完整局、289,861 次公開 API 操作**。21 配置每個各 126 局。最大完整存檔 **2,163,370 bytes**。
- **全部配置黑箱**：21 配置各一完整局，加感染 4、機械學通靈 1、惡靈騎士 4，共 **30 完整對局**；另相關板與專項 **9 局重跑**。均真實 DOM 選座／前進／回退／刷新／重開，非注入預造對局。
- **特殊介面**：24 角色圖鑑逐字技能、固定排序、快速分類、1.5 倍板子字級、320×568／768×1024／1024×768／1180×600，固定按鈕不遮復盤、主持座位無人物圖。
- **安全區模擬**：320×568／390×844／844×390／1024×768，top 47、bottom 34、可視高度縮短 20，10／12 人、一般／覺醒、清單上下與返回。按鈕仍 44px 高、列表捲動不移動底部按鈕。
- **混血兒真實 UI**：7 號跟隨 2 號，單一倒讚手勢、刷新／回退、警長警徽、三行卡及手機／平板文字邊界通過。
- **靜默快取**：CORE 安裝不等待人物；兩資產一批、有效舊圖 SHA256 重用、失敗後僅補缺、並行前景請求去重與獨立 Response、無關快取保留；完整後 **43 個現用圖／SVG／背景離線 200**。
- **回報連結**：獨立匿名瀏覽器開啟正確公開表單，未填寫／提交；返回 App 存檔字串一致，只有原 usp 參數，沒有遊戲資料。
- **素材**：53 正式原檔大小／SHA256 由完整測試核對，未修改本輪正式素材。快取 council-v13-1，存檔 v13 相容 v1～v12。

本機一次冷啟至可操作樣本約 **116ms**，僅為桌面 localhost 樣本，沒有慢網路或真機加速對照，不能宣稱手機達到此數字。詳見 [驗收統計](next-update-validation.json)。

- **真機首要**：iPhone 加入主畫面 PWA 與 Safari 底部按鈕、橫直向／重啟、原生外部連結開啟及返回；Android 亦未驗收。使用者已授權先部署供驗收。
