# 使用與驗收
Node.js 22+。不需安裝相依套件。`npm start` 後開啟 http://127.0.0.1:5173；`npm test` 執行 118 項測試。這是靜態 PWA，沒有另外的建置命令。

開始主持 → 10／12 人 → 板子 → 房規確認。原有黑狼王／魔術師與機械狼／通靈師均有 10／12 人版，狼兄狼弟／黑市商人只有 12 人。第一晚依操作提示辨識角色，未選足人數不能前進；其餘未辨識玩家於首夜結束記為平民。

主持字幕與法官提示分區。選座位記錄技能，明確選擇空刀／不交換／不使用才可跳過可用技能。耗盡或不具技能時，固定字幕仍保留。使用上一步可完整還原遊戲狀態。

狼弟復仇、商人交易、幸運兒能力依 README 第 31 章。商人必須同時選其他存活玩家及能力；可以延後。原有與額外能力分別消耗；兩把槍可選擇先使用哪一把，每槍都檢查勝負。

首頁只有開始主持／角色圖鑑。冷啟回首頁，主持中刷新恢復原局。主持頁重新開局沿用「繼續本局／回首頁」；回首頁會清除本局。發言計時器使用分秒滾輪，不自動跳到下一步。

遊戲結束顯示獲勝陣營、實際原因與夜間復盤。第一晚預設展開，多晚可同時展開。夜間正式死者不包含白天放逐或射擊。重新一局經確認保留房規／板子，清除其他全部資料；回首頁經確認清除本局。取消保留復盤展開狀態。

本機資料不跨裝置同步；只用一個主持分頁。舊版存檔缺少完整操作快照，不能補出不存在的復盤。實際 iPhone Safari／PWA 仍需真機驗收，詳見 [報告](feature-report.md)。

正式網站目前仍為舊版，本分支未合併、未部署。不要手動觸發發布，或在沒有確認時合併到會發布的分支。
