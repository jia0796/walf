# 執行與接管

- 正式網址：https://jia0796.github.io/walf/
- Node.js 22+，執行 npm start，開啟 http://localhost:5173 。無套件依賴。
- npm test：44 組規則、板子及 PWA 回歸測試；另有手機／平板實際瀏覽器檢查。
- README.md 是最新主持與遊戲規格。未定稿字幕不擴充，操作提示不混入字幕。
- public/data.js：角色名稱、分類、陣營、圖鑑、技能特性；10／12人板子的配置、夜間順序与可調規則。
- public/engine.js：流程、死亡、完整回退、抽籤、規則及自爆；public/app.js：畫面、設定、手勢、動畫及計時器。
- 初始設定：警長開、自救不允許、屠邊、吞警徽不啟用。README 未指定具體預設值；法官可於板子確認頁調整，開局後規則只讀。
- 座位環號碼遞增為順時針，右側遞增、左側遞減；10人循環在1–10，不包含未使用座位。
- 現版上一步還原完整狀態，包括已成立死亡；回退勝負也恢復到死亡前。抽籤結果缓存不重抽，相同名單可沿用，名單不同則失效。
- 舊存檔升級 version 3，保留角色、庫存與已有歷史。舊版本曾刪除的快照無法憑空還原；舊對局沿用當時允許自救的行為。舊交換紀錄只可由已保留歷史推回，缺失資料不臆造。
- 首夜候選名單在天亮前記錄。警上自爆中止當日流程；先處理未公布夜間死亡，下日退水直接投票。只計警長产生前有效自爆，12人雙爆／10人單爆可選吞徽。
- 新局使用資料化板子；主持座位沒有頭像。圖鑑七個角色使用 README 原文，image 欄位等待舊插畫原檔，沒有新增替代插畫。
- PWA：public/manifest.webmanifest、sw.js 與192／512圖示。首次連網成功載入後快取靜態資產，離線時仍可使用本機對局。實際安裝入口由裝置瀏覽器提供。
- 每局資料只存瀏覽器本機，不送到 GitHub，不跨装置同步。
- GitHub Actions 檢查後部署 public/；目前來源為 feat/eclipse-host-app，PR 合併後可縮限到 main。
