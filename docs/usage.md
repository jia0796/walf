# 使用與驗收
Node.js 22+。不需安裝相依套件。`npm start` 後開啟 http://127.0.0.1:5173；`npm test` 執行 193 項測試。這是靜態 PWA，沒有另外的建置命令。

開始主持 → 10／12 人 → 板子 → 房規確認。原有黑狼王／魔術師與機械狼／通靈師均有 10／12 人版，狼兄狼弟／黑市商人只有 12 人；夢魘／攝夢人有 10／12 人；新增「12人 預女獵白」及「12人 預女獵白混」。兩板白痴追刀預設關閉，可在本局規則調整。第一晚依操作提示辨識角色，未選足人數不能前進；其餘未辨識玩家於首夜結束記為平民。

主持字幕與法官提示分區。選座位記錄技能，明確選擇空刀／不交換／不使用才可跳過可用技能。耗盡或不具技能時，固定字幕仍保留。使用上一步可完整還原遊戲狀態。

狼弟復仇、商人交易、幸運兒能力依 README 第 31 章。商人必須同時選其他存活玩家及能力；可以延後。原有與額外能力分別消耗；兩把槍可選擇先使用哪一把，每槍都檢查勝負。

首頁只有開始主持／角色圖鑑。冷啟回首頁，主持中刷新恢復原局。主持頁重新開局沿用「繼續本局／回首頁」；回首頁會清除本局。發言計時器使用分秒滾輪，不自動跳到下一步。

遊戲結束顯示獲勝陣營、實際原因與夜間復盤。第一晚預設展開，多晚可同時展開。夜間正式死者不包含白天放逐或射擊。重新一局經確認保留房規／板子，清除其他全部資料；回首頁經確認清除本局。取消保留復盤展開狀態。

夢魘可選其他存活玩家或空恐，不能連續兩晚恐懼同一人；攝夢人必選其他存活玩家，不提供空攝。恐懼及梦遊不省略後續主持字幕，真正終局才中止。

本機資料不跨裝置同步；只用一個主持分頁。舊版存檔缺少完整操作快照，不能補出不存在的復盤。實際 iPhone Safari／PWA 仍需真機驗收，詳見 [本次驗收報告](classic-report.md)。

當晚開始時存活者仍可完成當晚行動；傷害先判勝負，座位死亡到公告才更新。真正終局時立即停止後續技能。2026-10-10 使用者已確認此規則並授權發布夢魘／攝夢人板子。
白痴被正式放逐會翻牌免死，不能再投票或被放逐；翻牌後仍可發言及被夜刀、毒殺。追刀關閉時翻牌算勝負已出局，開啟時要真正死亡才算。未終局的白痴警長須立即移交或撕毀警徽。

混血兒首夜必須選其他座位當榜樣，後續不可更換；法官卡顯示好／狼但仍民位配色，預言家一律驗好人。榜樣標記下一晚清除，榜樣資料保存整局；結束頁另外显示個人勝敗及第一晚綠色榜樣復盤卡。

幸運兒主持卡顯示原職業（幸）；額外能力仍獨立結算。復盤卡名為幸運兒，原職業平民用綠、神職用金，人物背景沿用原職業。
