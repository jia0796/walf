# 執行與接管

- 正式 App：https://jia0796.github.io/walf/
- 本機：Node.js 22+，執行 `npm start`，開啟 http://localhost:5173 。零套件依賴。
- 驗證：`npm test`，目前 26 組核心規則測試。UI 修改另需瀏覽器驗證。
- `public/engine.js`：流程、字幕、必要選擇、死亡事件、警徽及抽籤結果。
- `public/app.js`：座位、法官提示、SVG 手勢、共用抽籤動畫、計時與本機保存。
- `public/index.html`／`style.css`：畫面與暗黑月蝕風格。
- `README.md` 是使用者最新定稿規格；不得自行改主持台詞。新定稿字幕只有淘汰無遺言與警徽移交，其餘未定稿頁不補句子。
- 抽籤與視覺呈現分離：產生一次結果，揭示前鎖下一步；動畫跳過、刷新、回退皆不重抽。候選名單改變時才使舊競選結果失效。
- 座位環以 1→12 為順時針，死者右邊沿號碼遞增、左邊沿號碼遞減；自動略過死者。
- 警徽不移交按鍵使用 README 的「撕警徽／不移交」文字，未新增主持句子。
- 死亡公布後可回看字幕，但快照保留已成立死亡與紀錄，不取消或重複結算死亡。技能造成新死亡後，回退界線移到該死者的字幕。
- 已成立勝負仍顯示應有的死亡字幕，但不再開槍或處理警徽；第一天任何死因都有遺言。
- 本機存檔仍使用 `eclipse-host-v1` 儲存鍵，載入時將資料結構升到 version 2，保留原身分與藥品庫存；新功能不會清除既有對局。
- `.github/workflows/deploy.yml` 在 `main`／`feat/eclipse-host-app` 的程式更新後執行核心測試，再部署 `public/`。目前使用初版分支；PR 合併後可限縮為 `main`。
- 正式畫面沒有本局紀錄，事件紀錄只留於內部資料。
