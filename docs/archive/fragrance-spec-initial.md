### 57.4 尋香魅影：綁定選人、能力消耗與接刀

1. 尋香魅影屬狼人陣營，**不能自爆**；不與普通狼人一起睜眼。首次隨機認識一名普通狼人，但**不取得普通狼人共同刀權**；必須等普通狼人全部正式出局後才接手基本狼刀。
2. 每晚綁定能力仍可用且本人有操作資格時，可選**兩名彼此不同、當下存活的玩家**（可包含尋香魅影自己；亦可包含普通狼人隊友），或按獨立按鈕**「不綁定」**。按「不綁定」不消耗能力、不建立效果、不產生復盤卡；其他板子原按鈕不受影響。
3. 對座位的選取沿用**魔術師雙目標選取視覺與互動**：已選的座位再點一次取消；選一人時「下一步」不可按；**恰好兩名不同目標**才可按下一步；已選兩名再點第三人不生效；兩人**同等強調**、**不顯示①②次序**。這只借用選擇 UI，**不是交換身分、座位、技能或狼刀目標**。
4. 合法兩人選定並完成當次選擇後，**立刻建立一條當夜有效的雙人綁定**；效果延續至**下一晚正式開始前**，包含中間白天。可連續兩晚綁定同一人或相同兩人，不施加狼美人「不可連續魅惑同一人」限制。
5. 若有效期間一名綁定者**實際合法死亡**，另一名綁定者在**同一不可分割的死亡批次**因殉情出局，且**綁定能力永久消耗**。已被守衛／女巫解藥成功阻止的原始死亡不觸發殉情；守衛與解藥**不能單獨阻止已成立的殉情死亡**。
6. 若兩名綁定者在**同一原始死亡批次各自已確定死亡**：兩人各死一次、各自保留真實原死因，能力亦永久消耗；**不追加第三筆死亡、不改成虛假殉情死因、不新增殉情公告或殉情卡**。不同階段先後發生的狼刀與毒藥**不是**可任意合併的「同一批」。
7. 若當夜／白天未觸發任何使能力消耗的死亡，下晚開始舊綁定直接失效，能力保留，可重新綁定；**過期不刪歷史復盤**。一旦永久消耗且尋香魅影仍存活，往後每晚仍保留「尋香魅影請睜眼」／「尋香魅影請閉眼」，中間由主持畫面顯示**「綁定能力已使用」**，**不得再提供座位選取或「不綁定」**，不得產生假的綁定卡。遊戲終局則不再跑階段。
8. 普通狼人全部出局時，尋香魅影從**下一次仍能執行的基本狼刀階段**接刀，能選擇其他合法目標、**空刀、自刀**；依原有狼刀的合法目標、防護和傷害結算執行。自刀且自己為雙人綁定的一方時，若自身實際死亡，另一人跟隨殉情；自身被救或守護時不觸發。接刀不恢復已消耗的綁定技能。
9. 座位綁定標記使用**icon-bond.svg**，兩名座位均顯示技能標記與**對方座位號碼**；外觀沿用魔術師交換目標標記的既有風格，但**絕不互換目標**。綁定到期或實際殉情批次結算完成後移除當前標記；仍在效期的綁定**不因尋香魅影本人出局而提前消失**。
10. 第一晚隨機認狼結果必須**一局只產生一次並持久化**：隨機範圍是該局 2／3 名**普通狼人**，不能是自己或好人；重新整理、上一步、跨夜回退、讀取存檔**不得重抽**；建立新局才重新抽。**此提示不建立復盤卡**。

### 57.5 殉情、死亡原因、獵人、警徽與勝負（不得提前結算）

- **綁定當晚即可觸發**，包括首夜先刀後綁的實際死亡；女巫毒藥、白天放逐、獵人合法槍擊、尋香魅影接刀後自刀等合法原始死亡，均按「當時是否存在有效綁定＋是否實際死亡」判斷，不套用狼美人專有的毒殺／末狼／騎士例外。
- **尋香魅影本人出局後**，已建立的綁定仍維持至下一晚開始前；若白天其中一名綁定玩家被放逐，另一名仍跟隨殉情。**正式遊戲結束時**則停止綁定，不得再補死亡。
- **死亡批次原子性**：同一原始死亡造成的連動殉情先結算完，再統一判斷勝負；不可在最後一狼先死時就中斷殉情。若**同一批次**好人「狼人全滅」與狼人「神職或平民屠邊」同時成立，**狼人陣營獲勝**。狼刀、女巫毒藥與後續獵人槍擊依**各自獨立批次**結算；前一批次正式達勝立即終局，不再執行下一批、尚未執行的毒藥、警徽或公告。不能將「同一夜」等同「同一批」。
- **獵人（僅 12 人）**：因**殉情**實際出局者**不得開槍**；若獵人因**原始狼刀**等其他死因出局，遵守現有獵人槍權判定（如女巫毒殺依原規則不能開槍），不因「曾被綁定」一律禁槍。獵人死亡批次先判勝負；未終局且合法開槍時，其槍擊為**新死亡批次**，擊殺有效綁定者可在這一批引發另一人殉情；槍擊＋殉情同批完成後再判勝負。
- **公告**：夜晚到天亮時統一依原規則公告實際死亡**座號**，每人一次，不公告死因／身分／殉情原因；白天未終局且確實有殉情，沿用狼美人的**獨立公開頁**，逐字顯示「**X號玩家殉情出局，沒有遺言**」。殉情者**沒有遺言**，不因原始死者有遺言而取得遺言。若該批已正式終局，**不補放逐／槍擊結果頁、殉情公告、天亮死亡公告、遺言、警徽或未執行技能**。
- **警徽**：警長若因原始死亡或殉情出局，先完成其所屬死亡批次與勝負；**只有未終局才進入既有警徽移交／撕毀流程**，不能移交給當批已出局者；回退需一併恢復警徽。
- **邊界驗收**：兩人同批各自死亡只有兩筆原始死亡，沒有假的殉情；若其中一人死亡已由防護阻止，不能觸發；若尋香魅影自綁「自己＋最後平民」且自刀成功，雙方同批滿足勝負條件時按上述優先規則判狼人勝。對**未出局**玩家或已正式終局不可重複套用死亡。

### 57.6 覺醒預言家：雙人查驗、結果畫面及復盤

1. 每晚選取**兩名不同的存活玩家**，可包含自己一次；**不得選同一座位兩次**。雙人選取採現有單人預言家選座與結果手勢的原始互動樣式，只將必選人數擴為 2；第一晚完成身分登記後即可選兩人。
2. 選一人時下一步不可按，兩人時才進入現有預言家查驗結果頁；點已選座位可取消、改選目標。回到上一步時**保留原本兩人**，修改後再次確認必須**重新計算最終結果**，不能延用舊手勢或提早透露第一名目標結果。
3. 對兩人分別按**普通預言家既有的真陣營查驗語意**判定；**兩人皆好人＝👍／好人；至少一人狼人＝👎／壞人**；不告知哪一個是狼。夜晚**實際結果頁**沿用原預言家 👍／👎 圖示、動畫、返回與主持動作，**不可改成復盤文字畫面**。
4. **完整復盤**才在既有 **icon-inspect.svg** **上方顯示「好人」或「壞人」文字**，不是 👍／👎，也**不是**現有單人預言家可能使用的「狼人」字樣；左側覺醒預言家本人，右側兩名真實查驗對象上下排列，融合人物原畫與實際座號／職業，但**不標哪個目標是狼人**。如選自己，左側與右側出現同一人物為合法，不代表兩次技能。
5. 普通預言家在**其他板子仍每晚只查驗一人**；其他角色的查驗結果及原有復盤文案都不能被這項雙人邏輯覆蓋。

### 57.7 主持選人、上一步、復盤資訊卡與真正事件

- **尋香魅影雙人綁定卡**：每次正式選兩人，只建**一張**卡；**左側**尋香魅影（角色、號碼、已核准原畫），**中央**專用 **icon-bond.svg**，**右側**兩名被綁定者（上下排列，各自真實職業、座號、人物原畫）。不要①②順序，不要「生效中／已觸發／已消耗」等附加結果字。選擇「不綁定」、取消或根本未執行時**不建卡**。第一夜卡與第二夜相同兩人再次綁定卡**分別保留**，不能覆蓋。
- **尋香魅影殉情卡**：**實際增加一名殉情死者時**另建獨立卡；**左側是原始死亡的被綁定對象（不是固定尋香魅影）**，中央沿用狼美人的 **icon-heartbreak.svg**，右側是實際跟隨殉情的人。真實原死因的狼刀／毒藥／放逐／獵人槍擊卡**另外保留**，不能覆蓋或重複；兩名綁定者同批各自死亡時**不能虛構殉情卡**。
- **基本狼刀卡**：普通狼人仍存活時沿用原版狼人刀卡；**尋香魅影正式接刀後**的狼刀事件卡左側改顯示**尋香魅影本人**（原畫、職業、座號），中央使用原有狼刀 SVG，右側實際選定刀口（含自刀時同一人物可左右各出現一次）。空刀依現有原版對空刀的真實事件處理，不額外造出局卡。
- **覺醒預言家查驗卡**：左側覺醒預言家、中間原有查驗 SVG **上方是「好人／壞人」文字**、右側兩名查驗玩家上下排列（職業、座號、原畫）；**不能把夜晚手勢 👍／👎 放在復盤卡上代替結果文字**。
