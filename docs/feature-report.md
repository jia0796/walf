## 分階段結果

1. 規則／結算：新板子在同一夜間引擎，兩刀獨立；普通狼刀資訊與復仇刀分開；狼兄正式出局當下記錄下一晚復仇、再下一晚加入。原板子的防护與刀優先勝負沿用。
2. 主持流程／技能：首夜一次辨識，第二晚起狼弟三頁固定保留；交易須同時選目標與能力，可以延後；額外查驗／毒下一晚起、槍下一個白天起；原有與額外能力分開消耗／回退。獵人兩槍逐槍判勝負、子死亡先處理、最後才移交警徽。
3. 正式素材／復盤／結束頁：九款 SVG 共用，槍統一 icon-gun.svg。勝利區無人物。復盤依實際夜間流程快照排序，只列執行事件；狼刀終局中止的毒事件不列卡。正式夜間死者與白天射擊／放逐分開。第一晚展開、其他晚收合，取消確認保留展開狀態，刷新不重算。
4. 回歸／UI：既有五種人數配置共用警長、抽籤、投票、PK、吞徽與死亡流程。重新一局保留板子／房規并清除前局；回首頁確認後清除本局。首頁兩顆真實導航按鈕與三排計時器依最新 README 補齊。

## 待確認與尚未解決

1. **狼弟夜間自爆**：README 31.1 明訂所有兄弟角色狀態皆可自爆，已在既有白天自爆流程開放，不受加入普通狼隊資格限制；未自行增加夜間中斷的流程。若「任何階段」也包含夜晚，需要確認是中止本晚進下一晚，還是處理死亡後繼續未完成的夜間角色。已提出問題，尚未收到回答。
2. **三人以上無警長抽籤**：新板子確實可能出現三人以上夜死，現有引擎已能依死者參照座位／方向找最近存活者。README 14.3 只明訂 0／1／2 人範例；本次沿用舊算法，不另造新规则，是否正式採用仍待確認。
3. **既有三重防護与非狼刀同時終局**：無敵盾、守衛＋解藥同目標的組合，以及兩瓶毒／交易失敗同批死亡令兩陣營同時達條件，README 沒另定新死因順序。保留原先盾優先、非狼刀同批結果與真實陣營判定，不自行擅改；有不同裁定需先確認。
4. **舊版歷史復盤**：v1–v5 可升級，角色／房規／庫存／回退保留；缺少操作快照的過去夜晚無法完整還原，畫面明示限制，僅列更新後實際記錄。沒有把死者反推成技能卡。
5. **Safari／iOS PWA**：目前沒有可操作的真實 iPhone Safari／主畫面 PWA。冷啟、背景返回、離線安裝、工具列伸縮与實際安全區须真機驗收；未宣稱通過。

## 需要討論的優化（未擅自改動）

- 長局完整快照會重複保存歷史事件；此次樣本最大約 1.2 MB JSON，瀏覽器配額與字串計量各異，極長局可能保存失敗。可討論 IndexedDB 或可回退的增量快照；不裁切舊歷史。

- 真機驗收優先於額外動態特效、重新設計流程或新增角色。
