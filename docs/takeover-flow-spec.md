### 1. 共通規則

- **基本接刀資格只在每晚開始時計算**：前一白天最後原始狼人出局，下一晚才能接刀；當晚夜間中途全滅不追補狼刀。機械狼、假面、尋香魅影於本板所有原普通狼人出局且自身存活時接刀。**轉化者**須原普通狼人及覺醒石像鬼全部出局，且已成功轉化、本人存活、符合原 joinNight 加入時機，才接刀；轉化者自己不列入原始狼人存活數。**轉化必定成功，不存在「轉化失敗」狀態。**
- 四種角色的基本狼刀與機械狼學狼人取得的額外狼刀**均可自刀、可空刀**；可以跟原本技能同晚使用，也可指定相同座號；保留各自技能限制。機械狼兩把刀可同晚各刀一次，同人亦可，兩次獨立傷害／使用紀錄。
- **角色「請閉眼」畫面按下一步，才正式提交**狼刀與技能結果；此前可自由選擇、取消、修改。閉眼主字幕不變，僅有狼刀資格時顯示小字目標或空刀摘要（機械狼基本／額外分開）。空刀可直接下一步，不建假攻擊。
- **所有原普通狼人出局後，原狼人階段保留「狼人請睜眼」→「狼人請閉眼」**，不再顯示「選擇你們今晚要襲擊的對象」，座位環照常顯示但不能選刀；接刀特殊角色在此不再操作。同時仍有原普通狼人時原狼人選刀流程不變。不得因轉化者被統計為狼人而使原狼人階段重複操作。
- 四種角色即使死亡，後續未終局的夜晚仍照常顯示完整專屬字幕、固定步驟及座位環，但技能與狼刀均不可操作；終局不再入夜。
- **只更換基本狼刀選取的位置，不改結算**：女巫得知基本狼刀刀口（包含自刀），不因機械狼額外狼刀得到第二刀口；守衛、解藥、同守同救、傷害批次、殉情與勝負依原有邏輯。雙刀同人仍為兩筆獨立傷害，一次解藥不自動抵擋兩次。已提交狼刀後該角色當夜死亡，攻擊仍正常結算，不在選刀時提前判出局。
- 上一步、重整與讀取存檔要恢復資格、目標、技能、消耗、刀種分頁及復盤；**修改基本刀口後只清掉與新刀口衝突的解藥等相依資料**，不清守衛、毒藥、額外刀及不相干技能，重算死亡、殉情、勝負與卡片，不產生重複紀錄。必要時升級存檔版本並向下兼容，不補造舊存檔歷史。

### 2. 四個角色夜間流程（維持其他角色順序）

**機械狼／通靈師（10／12 人）**
- 第一晚原位置：**機械狼請睜眼 → 選擇你要學習的對象 → 機械狼請閉眼**；其他首夜階段順序不變。
- 第二晚起順序：守衛 → **機械狼** → 狼人 → 女巫 → 通靈師 → 獵人（12 人）。機械狼固定字幕：**機械狼請睜眼 → 今晚的帶刀狀態 → 選擇你要學習的對象 → 選擇使用技能的對象 → 機械狼請閉眼**。
- 已學習也照念「選擇你要學習的對象」，不能重複學習；無可用主動技能仍照念「選擇使用技能的對象」，小字顯示「本晚無可使用技能」，不影響狼刀切換。
- **基本狼刀**需原普通狼全滅；**額外狼刀**僅在已學習狼人且符合原有額外刀房規／解鎖／使用次數時開放，不因未接基本狼刀而停用。兩刀獨立選人、提交、傷害、消耗和復盤。

**轉化者／覺醒石像鬼（10／12 人）**
- 第一晚維持守衛 → 狼人 → 覺醒石像鬼 → 女巫 → 預言家 → 守墓人 → 獵人（12 人）→ 轉化者確認身分；轉化者必定成功，沿用原職技能。
- **第二晚起新增固定獨立階段，放在守衛與狼人之間**：守衛 → 轉化者 → 狼人 → 女巫 → 預言家 → 守墓人 → 獵人（12 人）。字幕固定：**轉化者請睜眼 → 今晚的帶刀狀態 → 轉化者請閉眼**。只在帶刀狀態頁面操作狼刀，無額外右側切換；未具資格或已死可直接跳下一步，字幕不消失。
- 復盤及座位身分沿用「轉化者（原職簡稱）」。

**假面／舞者（12 人）**
- 首夜維持舞者 → 假面（認身分）→ 狼人 → 女巫 → 預言家 → 白痴。
- 第二晚起：舞者 → **假面** → 狼人 → 女巫 → 預言家。假面字幕固定：**假面請睜眼 → 今晚的帶刀狀態 → 請選擇你要查驗的對象 → 獨立「-」查驗結果畫面 → 請選擇你要賦予面具的對象 → 假面請閉眼**。查驗結果仍另外顯示，不可用狼刀介面覆蓋。

**尋香魅影／覺醒預言家（10／12 人）**
- 首夜維持守衛 → 狼人 → 尋香魅影（固定認出其中一位狼隊友、綁定）→ 女巫 → 覺醒預言家 → 獵人（12 人）。
- 第二晚起：守衛 → **尋香魅影** → 狼人 → 女巫 → 覺醒預言家 → 獵人（12 人）；字幕固定：**尋香魅影請睜眼 → 今晚的帶刀狀態 → 請選擇你要綁定的對象 → 尋香魅影請閉眼**。
- 綁定永久消耗後仍念「請選擇你要綁定的對象」，下方小字「綁定能力已使用」、禁止再次綁定；取得接刀資格時狼刀仍可用，原綁定／殉情規則不動。

### 3. 操作入口、顯示與紀錄（全部沿用現有 UI）

- 帶刀狀態頁顯示可否帶刀，能選時可直接選刀或不選下一步。**機械狼學習／技能、假面查驗／賦面、尋香魅影綁定**的選人畫面右側有「狼刀」按鈕；只有實際可用刀種時才顯示。假面查驗結果、角色睜眼及閉眼畫面均不顯示。**轉化者只在狀態頁直接操作。**
- 點狼刀後主字幕**不變**，只在座位環上方顯示小字「狼刀選擇」；點回技能續做原操作。切換不增夜間步驟、不清技能／狼刀目標；按下一步自動顯示下一個正常字幕的原介面，上一步可還原修改。
- 技能、基本狼刀、額外狼刀各自保存選取，**原座位環同時顯示所有既有 SVG 標記**，直接沿用 public/app.js 的 skill-marks、public/engine.js 的 syncMarks／markersForSeat 及 public/style.css 原本位置、尺寸、重疊排列；不得重設標記系統、在座號下方另加一排、改變其他角色圖示或原有布局。
- **機械狼雙刀 UI**：帶刀狀態分列基本與額外刀。額外刀依「未取得／尚未解鎖／可以使用／已選目標（未正式提交）／已使用（提交後）」顯示。已耗盡的額外刀仍在狀態列顯示「已使用」，不出現在可操作分頁。狼刀介面用既有座位環在基本／額外間切換；僅一刀可用時直接顯示該刀。同一晚再次進入記住最後刀種；**新夜晚**兩刀目標清空、首次優先可用基本刀否則額外刀，但永久學習結果、歷史與已用次數不重置。
- 額外狼刀只有**非空目標正式提交攻擊**才扣使用次數；開介面、切刀種、取消、空刀不扣，被守住或救活仍扣；基本刀不扣額外刀次數。
- **復盤**：沿用所有原有人物背景與資訊卡樣式，施刀者使用真實角色身分。機械狼同晚雙刀固定**基本狼刀卡在前、額外狼刀卡在後**；**只有額外狼刀卡**的既有狼刀 SVG 正上方增加小字「額外狼刀」，基本刀及其他接刀卡不加新標題。空刀及空狼人階段不造狼刀卡。同一玩家同批只出局一次；不同攻擊、技能、擋刀、救治紀錄保持獨立，死亡資訊卡保持原本格式。
