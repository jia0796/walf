共享結算新增狼刀／後續死亡批次。可用防護與解藥確定前不判勝負；狼刀已終局時不執行後续毒／攝夢死亡／查驗／交易／竞選，轉天亮再結束。同一不可拆分批次雙陣營達標判狼人勝。未執行傷害不列復盤，已使用但遭夢遊免疫的毒仍耗藥且保留紀錄。睡眠卡僅確實連續攝夢致死才註記。

存檔 v7 保存上一晚實際恐懼／攝夢、待死亡、分批結算、庫存、原始座位標記及復盤。兼容 v1–v6。重新一局沿用板子和房規，其餘清除。

主持頁全面沿用精簡 SVG 操作，人物背景僅圖鑑與結束復盤。兩張 PNG、兩款 SVG 為 Drive 已核定原始檔案，不改繪；技能圖示共十一款。來源／位元組大小／SHA256 見 assets.json。

## 真正待確認的規格

README 16／16.1 要求每個夜間階段正式结算死亡，不必等後續查驗／交易；31.3 同時保留「商人當晚被刀死，成功交易依然有效」，且交易頁在狼刀之後。35.2 又要求已死亡角色保留字幕，但沒有明確區分「前夜已公告出局」與「當晚剛正式結算、尚未公告出局」的技能資格。

已向使用者提出兩種處理方式，尚未取得回答：
1. 當晚開始時存活者仍可完成當晚行動；傷害先判勝負，座位死亡到公告才更新。
2. 正式死亡立即停用其後續技能，僅保留死亡前已完成的效果。

本分支暫保留原有當晚行動資格，正式死亡另記於 nightState，公告時更新座位；以此行為跑測試。**此部分不是自行新增的定稿規則，確認後仍可能需要修改、重跑回歸。** 終局中止與狼刀優先不受此待確認項目影響。

27.3 舊「非狼刀同批勝負待確認」與第16／35的最新定稿衝突，已按明確的最新全域規則採同批狼人優先，無需再猜規則。
