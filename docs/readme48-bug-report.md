# README 48：種狼／隱狼、背景與多輪驗收報告

規格來源：main@7236c78；歷史第 1～47 章沿用 docs/specification.md，本輪第 48 章、固定板子排序與五張背景更新優先。基礎 App：feat/eclipse-host-app@9c7519c。

## 實作結果

- 新增 seedHidden10／seedHidden12，總共 21 種可主持配置、24 種角色圖鑑。一般板子按定稿固定順序排列，10 人自動排除三個 12 人限定板；覺醒石像鬼維持獨立分類。
- 沿用共用主持、身分、夜間傷害、勝負、白天警長／放逐、自爆、快照及復盤模組，未另建 App。
- 種狼第二夜起可保留並使用一次感染，以共同刀目標取代狼刀；選座與切模式不消耗，正式二次確認後才消耗。取消不記錄；失敗不補刀。
- 守／救阻止感染；同守同救仍以原身分死亡，包含種狼自己及其他狼。合法解藥照常消耗。
- 成功感染即刻改真實狼人陣營、永久停原技能；下一夜才參與基本刀，隔天可自爆並計入吞警徽。原職、感染夜、結果、警徽及最終陣營均保留。
- 隱狼驗好、不相認、不刀、不接刀、不自爆；只剩隱狼立即好人勝。新感染帶刀狼尚未到下一晚也能阻止誤判好人勝。
- 當晚開始存活者可完成合法行動；正式感染與傷害先判勝負，座位死亡到公告更新。提前終局停止後續毒、查、獵人及通知。
- 第二夜起保留「襲擊或感染」及三句感染確認字幕，即使未發動、失敗、用完或種狼已死。當夜成功者毒死仍通知；已正式終局例外。未改既有定稿字幕或圖鑑文案。
- 隱狼不新增睜眼字幕：法官在既有「請確認角色身分」頁私下先登記隱狼，再走原首夜流程。狼人階段僅登記種狼和普通狼人。
- 感染者座位原職（已感染）、狼人配色；技能鎖定提示「已被感染，無法使用技能」。感染成功／失敗均有已執行的獨立紅卡，未發動／取消不造事件，失敗不補刀卡。
- 存檔 v12 相容 v1～v11，連同歷史快照遷移；刷新不重扣、不重結算，重開清除感染紀錄並保留房規。
- 使用正式 icon-infect.svg；原 16 SVG 保留，現在 17 款。種狼與隱狼沿用已核准人物原檔，未重新生成。
- 依 Drive 同 ID 最新檔更新五張背景 PNG，保留原檔並製作等尺寸 WebP。獨立固定裝飾層不接收操作，背景 cover，外層不捲動、前景容器局部捲動，處理 viewport 及安全區。

## 本輪發現及修正

| 類型 | 發現 | 處理 |
|---|---|---|
| 實作問題 | 選目標後切換襲擊／感染，標記只比對來源與座位，可能留錯 SVG | 標記比對加入技能類型，撤換舊圖示；補前後切換測試 |
| 規格新增 | 新板帶刀資格、成功轉陣營與鎖原技，不能直接套石像鬼規則 | 分開 infection 與 gargoyle 狀態，共用 realWolf／nativeAllowed 與結算 |
| 規格優化 | 板子次序依新增歷史排列，未符合新固定順序 | 以固定資料順序排序及過濾，UI 驗證正確 ID、不漂移、切換回頂 |
| 規格優化 | 背景需固定而舊版以整頁背景及捲動處理 | 改固定不接收操作底層及前景捲動，正式 PNG／WebP 更新 |

測試開發中另修正舊測試寫死存檔 v11／種狼未實作、黑箱缺少隱狼登記與感染狼放逐、收合復盤需查 textContent、雙背景層 computed cover 數值等測試假設。這些不冒稱已確認的既有產品 Bug。

## 尚待驗證及優化

1. **iPhone Safari／iOS 安裝 PWA／Android／低階裝置真機**仍未驗收。桌面 Edge、模擬 viewport、字級與離線不能代替真機的安全區、慣性捲動、背景切換或效能。
2. **長局保存與多局記憶體**：存檔接近 1.84 MB；先量測真機每步保存成本，再討論 IndexedDB，不刪回退歷史。
3. **多分頁保存衝突**仍採單一主持分頁；不擅自新增同步規則。
4. **大型人物離線成本**仍可另討論衍生圖與分段快取；本輪只依授權壓縮背景，核准人物原檔不變。
5. 固定板子列表已加入 **1.5 倍字級**與標題／返回按鈕不隨內部捲動檢查；全系統字級及無障礙縮放仍需真機驗收。

本輪未保留已確認未修正的遊戲功能失敗；不宣稱全部極端組合已窮舉。規則未定稿部分未擅自新增。
