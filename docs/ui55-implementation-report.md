## 已完成與已修復

- 警上白／銀框＋「警上」、退水灰藍框＋「退水」，維持到警長正式投票、PK 與重新投票；當前結果被選取時用紫框強調，標記保留，取消即恢復白框。一般放逐頁不留下競選標記。
- 「紀錄票型（選用）」獨立彈窗，預設「多人投同一位」，亦可直接逐人紀錄。批量改投、點同票取消、棄票、未紀錄、兩模式同步、合法自投與二次確認清空本輪全部完成。彈窗與統計不會替主持人選結果、當選、放逐或開啟 PK；原直接選結果→下一步保持可用。
- 警長投票／PK 只列自始未上警且依既有流程有票權者，不因退水恢復票權；逐字提示「上警與退水玩家不參與本輪投票」。目標僅取原合法票池，PK 限該輪候選。進度分母是實際合法投票者數，不寫死 12。
- 第一輪與 PK 分開保存，PK 初始未紀錄。放逐警長 1.5 票、其他 1 票，警長選舉一律 1 票；棄票不加票，未紀錄不當棄票。排序按票數降冪、同票座號升冪；同票提示不觸發判定。
- 當輪警長、投票者、目標與權重來源保存快照，後來警徽移交不改舊票。座位與得票者分組旁只用網站既有警徽 SVG，不另寫警長／1.5 票文字；合法合計票數照實顯示。
- 原事件卡的 HTML 與人物／投票箱／中央圖示／配色完全保留，只有有實際票型或棄票的投票事件卡下方增加預設收合「查看投票紀錄」。得票者分組，棄票獨立，未紀錄不顯示；PK 兩輪各自統計、各自可展開，不把第一輪重複累加。
- 混血兒回到原座號＋「混血兒（好／狼）」單一角色名稱，移除主持座位的三行榜樣／陣營排版。只改顯示層，真正榜樣、技能標記、查驗與勝利歸屬仍保留。
- 視覺驗證修復通用已選按鈕樣式蓋過票型紫框的問題；統計、捲動清單與固定完成按鈕不改座位按鈕順序。
- 存檔 v19 支援 v1～v18，舊局及回退快照僅新增空票型資料，不補造歷史票。票型沿用本局與完整回退快照，不另建儲存系統。新局／重新一局清空前局票型。PWA council-v19-1 把兩個新模組加入既有 CORE，素材摘要仍 86 項。
