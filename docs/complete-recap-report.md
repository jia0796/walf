## 完成內容

- 全 App 使用同一正式 PNG，共用固定裝飾層，頁面只調遮罩。舊五張 PNG／WebP 不再引用、預載或快取，Git 歷史與 retiredBackgrounds 索引保留來源紀錄。
- 完整復盤依第一晚／第一天等連續顯示，不收合、不分頁；夜間死亡集中在當晚結果。遊戲結束只顯示陣營／原因，最終身分直接放面板底部，狼區在上、好人區在下，各依座號雙欄。
- 夜间雙人物卡：正式原畫、職業上／號碼下、中央正式 SVG。狼刀無個人號碼；交換保留兩目標；原始與實際映射並存；機械學技、幸運兒、感染者／轉化者按事件時點顯示。
- 警長競選與放逐採正式插畫／事件名／SVG／職業號碼／人物五區塊；PK 名單與最終結果、白痴翻牌、自爆、合法槍擊、警徽移交／撕毀依实际順序保存；不存票型、不製造未發生流程、吞警徽無獨立卡。
- 交易失敗不顯示拟贈能力；感染標記具體防護原因；反傷標記毒／查來源；攝夢標記連帶／連攝；多刀同目標保留獨立事件。沒有修改 public/night.js 的傷害與勝負規則。
- 正式新增投票／警徽 SVG 兩款與兩張事件插畫，五個原檔 SHA256／大小通過，原角色／17 SVG 未重畫。現用技能 SVG 為19款；存檔仍 v13，新增可選快照欄位，相容舊局及完整回退。
- PWA cache council-v13-3；核心優先、二資產分批、重用／續載及完全靜默原流程不變。

## 發現並修正的問題

1. 夜間终局座位未公告時，身分回顧不能用座位 alive 直接判存活：改讀正式 nightState.deaths，但主持座位更新時點不變。
2. 未認角色快照包含 undefined 陣營欄位，JSON 存檔會刪除該欄位：改存明確 null，刷新／回退比對穩定。
3. 新毒藥結果要依獨立來源對應，避免同目標原毒／額外毒的防護資訊相互污染。
4. 第一輪黑箱用舊文字「感染成功」斷言失敗：規格新標記是 SVG 上方「成功／失敗」，調整測試定位後重新跑所有專項通過。這項是測試與 UI 定稿不一致，非遊戲規則失敗。
